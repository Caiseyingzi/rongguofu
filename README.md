# 荣国府 · 图纸校准模型

[打开交互模型](https://caiseyingzi.github.io/rongguofu/) · [下载 OBJ 三维模型](https://caiseyingzi.github.io/rongguofu/rongguofu-model-obj.zip)

依据所附荣国府平面示意图描摹的交互模型，保留原图纵横比例、院落位置和门道关系。可选择院落、拖动与缩放、揭开屋顶，并切换原图叠合核对。

![交互模型总览](preview.png)

## 使用

直接打开 `index.html` 即可使用，原图、样式和交互脚本均已内嵌，无需安装依赖。网站通过 GitHub Pages 从 `main` 分支的根目录发布。

- 选择院落，拖动画布平移，滚轮或加减按钮缩放。
- “平面核对”中可调节原图显影透明度、显示或隐藏建模轮廓。
- 键盘左右键切换区域，Home 回全府，1/2 切换立体与平面，R 揭顶，F 适合画面。
- 手机可横向滑动院落名称。

## 模型说明

平面布局依据用户提供的 1005 × 2948 像素示意图。所有建筑使用同一套原图坐标，未分别拉伸横纵比例。

原图没有实测尺寸与立面，因此不换算米数；建筑高度、屋面坡度及柱窗细节为示意。这个模型用于辅助阅读和空间理解，不代表历史建筑原貌。

OBJ 与 MTL 需放在同一文件夹后导入三维软件。三维文件采用无量纲显示单位：1 单位对应原图 10 像素，X 向东、Y 向北、Z 向上。

## 更新网站

更新根目录的 `index.html` 后推送到 `main`，GitHub Pages 会自动重新发布。发布文件可独立使用；本仓库不需要构建步骤。
